# SkyBridge
**A Cloud-Native Learning Journey with Azure, IaC, and AI**

## 🚀 Purpose
Re-familiarize with coding, learn Infrastructure as Code (IaC), and explore AI-assisted development in the cloud era.

## 📂 Structure
- `/terraform`: Terraform files for Azure resources.
- `/scripts`: Helper scripts for automation.
- `/docs`: Documentation and notes.

## 🛠️ Tools
- [Terraform](https://www.terraform.io/)
- [Azure CLI](https://docs.microsoft.com/en-us/cli/azure/)
- [GitHub Actions](https://github.com/features/actions)
